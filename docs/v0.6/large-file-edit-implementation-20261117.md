# P0-B 大文件读取和编辑反馈

大于 800 KB 的文本文件使用有界逐行读取和整文件哈希，返回指定行与可编辑快照。读取期间限制单行长度并复核文件哈希。大文件编辑根据快照允许的行范围写入同目录临时文件，流式计算原文件和新文件哈希，再次核对原文件哈希后使用 os.replace 替换；保留 BOM、所编辑行的 LF/CRLF 与文件权限位，输出所选行的局部差异及版本哈希。替换前检查执行工具的 editable 策略，失败时清理临时文件。

Python 文件创建和行编辑后使用运行器当前解释器的 ast.parse 给出提示，错误反馈包含行、列与原因。结果标记 advisory，不阻断中间状态，允许继续修改；超过 2 MB 的文件不执行该语法检查。运行器解释器不一定与目标环境相同，结果只说明该解释器下的解析情况，目标解释器兼容性仍需实际运行确认。

本批仅执行 AST 和静态差异检查，尚未运行大文件读取、编辑、异常恢复、并发写入或语法诊断测试。P0-B 实现已接入，行为及 Windows 文件替换竞争条件仍待定向验收，不能据静态检查宣称已验证。目标环境解释器的语法检查尚未接入。

后续补充：开发检查的候选容器在执行测试前，使用 testbed 解释器对补丁涉及的 Python 文件运行 py_compile。语法失败时返回 syntax_error 与目标解释器输出，不将其归为检查基础设施异常。该检查在调用 run_tests 时执行；编辑后的即时提示仍使用运行器解释器。该补充尚未运行测试或容器验收。
