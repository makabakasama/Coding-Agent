## 本批实现

- `grade` 改为通过随轮复制的独立启动脚本调用官方 swebench 5.0.2，使用指定评分解释器，项目基础依赖不增加 Docker 或官方评分包。
- 每轮复制冻结题目与 predictions，保存脚本、输入、预测的 SHA256；从源仓库固定 commit 取得预期 tree。命令预览只读取本地材料与 Git，不启动容器。
- 显式 `grade --execute` 才连接 Docker：解析官方镜像为实际 image ID，以无网络、无宿主挂载的专用容器读取 HEAD、tree、工作区状态及目标 Python。探测容器停止后保留。
- 源码不符时，从实际 image ID 建立专用派生镜像，在容器构建层内恢复固定 G，重新核验；不操作宿主源仓库或 Agent 副本。构建禁止网络，流式保存构建日志，失败不进入评分。镜像原本缺少 G 时停止，不自动补抓历史。
- 只修改评分输入副本的 image 字段，保留原测试补丁、命令、评分清单与原始输入。已核验的镜像 ID 直接交给官方评分器。
- Windows 下仅对官方生成的 eval.sh、patch.diff 强制 UTF-8/LF；退出时恢复文本写入行为。保存实际脚本和补丁的哈希、CRLF 数量。
- 评分进程非零退出或超时不导入成功成绩，保留 unknown 和输出。导入报告仍不自动宣称完成全流程独立验收。
