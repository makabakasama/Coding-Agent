# Chat 主链路定向离线验收

日期为 2026-11-11，北京时间。用户已明确授权测试，B1/B2 与 B3 前端的指定主线和故障分支通过本轮定向离线验收。

| 范围 | 结果 | 证据类型 |
| --- | --- | --- |
| Chat 专项 | 16 passed，8 subtests passed | 脚本模型、真实临时 PostgreSQL、HTTP 和独立 Worker |
| 相关后端回归 | 65 passed，2 skipped，114 subtests passed | Provider/队列/任务/重载/数据库与文件 IO 定向检查 |
| 既有前端 | 66 passed | 最小 DOM/模拟 fetch 行为检查 |
| 实际浏览器 | 7 个场景通过，Node 含父项合计 8 passed | Headless Chrome、实际页面、临时 HTTP/数据库及独立脚本 Worker |

两个跳过项需要专用 Redis 地址，本轮未配置。检查通过覆盖选定范围，完整后端、真实 Provider 效果及系统化任务评估仍待安排。

页面验收覆盖多轮回复、代码/文本安全展示、草稿与历史刷新恢复、同一请求编号重试、失败/材料查看、会话切换时的晚到响应、实际双标签页冲突、窄屏和原编码入口。网络故障使用受控注入，实际模型为脚本替身。另完成 Worker 进程真实终止/重启、已保存结果恢复、混合队列和材料哈希异常检查。

本轮修正会话未就绪时的提交保护，以及 Windows 原子替换期间的短暂读取 PermissionError；补齐读取重试的成功与持续失败检查。旧前端夹具补上浏览控件节点，原断言保持。

初次失败与后续复测材料完整留在本机报告目录。测试目录过深曾触发文件创建失败，最终使用较短隔离目录；Windows 超深材料路径支持仍有限制。首次终端输出解码有部分替换字符，原始终端字节未保存，JUnit 保留，后续输出统一 UTF-8。

本机完整输出、JUnit、85 个相关源码归档/指纹及截图见 [验收报告](../../runs/engineering/chat-acceptance-20261111-140115_dd8f3798/summary.md)。runs 材料被 Git 忽略，本机留存与源码提交分别管理。临时测试进程与本轮新建数据库已清理，文件证据保留。
