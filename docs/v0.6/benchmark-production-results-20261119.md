## 未评分原因与恢复范围

- **Django 15400 两次**均有候选补丁。以启动器权限执行基线仓库的 `rev-parse`，复现了 Git 所有权冲突和退出码 128。为该命令临时指定已核验仓库的 `safe.directory` 后，读取同一基线 tree 成功。准备和工作进程使用了路径限定授权，评分入口再次访问基线时未继承该授权。
- **Django 16229 A、SymPy 24213 A/B、scikit-learn 12471 A/B** 均有候选补丁，评分进程因缺少同目录的 `image_provider` 模块而退出。两份 pytest 评分脚本和生命周期文件匹配预注册 SHA256，后五份评分脚本的 SHA256 已变化。生产启动时校验了评分器源码，但每次评分从可变工作区读取脚本，加载到进程中的打包逻辑与后续复制的脚本出现版本漂移。该共享评分故障出现后队列继续启动了后续任务。
- **另外五次**的候选补丁为空。最终结果保留 `UNSCORED`。
