## 数据组织与兼容

工作台新普通任务为 `runs/<taskKey>/run_<轮次ID>/`、`experiments/<项目>/workspaces/`，需求级 task.json 与轮次快照分开；固定实验保持 `runs/<实验名>/run_<轮次ID>/`、`experiments/<项目>/workspaces/`。旧普通任务继续从 `runs/tasks/task_<ID>/` 及原副本位置读取，未做物理迁移。结构见 [统一数据模型](data-model.md)和[普通轮次契约](ordinary-rounds-api.md)。

本次没有移动、清理或重写原始实验材料，旧任务编号及链接保留。`runs/` 与 `experiments/` 被 Git 忽略，本机留存不等于远端备份。
