三类共用：任务页选择项目与类型 → 保存约定 → 准备独立副本 → 确认启动 Agent → 查看结果 → 从普通任务记录重新打开。

| 类型 | 需求填写 | 修改权限 | 交付内容 |
| --- | --- | --- | --- |
| 阅读代码 `read_code` | 当前行为填写背景或问题，期望行为填写希望解释的内容 | 禁止编辑，提交空 allowedPaths | Agent 分析总结、读取步骤、无修改审查 |
| 修复 Bug `fix_bug` | 缺陷触发方式和预期行为 | 仅允许路径内业务代码 | 修改、差异、固定检查和总结 |
| 补充小功能 `add_feature` | 现有能力和新增行为 | 同修复任务 | 修改、差异、固定检查和总结 |

阅读时修改范围输入框禁用；切换回修改任务会恢复之前填写的范围。测试权限独立选择，运行测试必须指定固定目标。固定检查没有执行或没有通过，结果照实保留。阅读总结仍是模型分析，不能据此证明其结论正确。
