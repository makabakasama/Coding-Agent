# Coding-Agent 项目推进计划

更新日期：2026-11-23（北京时间）。当前阶段为 v0.7 后端规划，工程状态见 [status.md](status.md)。

## 项目目标

面向 Python 后端 / AI 应用开发求职，形成可演示、可解释、可核验的简历项目。

项目同时交付后端服务和 Coding Agent。后端负责接收任务、可靠调度、状态查询与结果交付；Agent 负责仓库修改、公开检查与补丁生成。后端验收考察任务在并发和故障下的交付行为，Agent 求解能力沿用[冻结阶段的评测口径](v0.6/harnesstax-outcome-plan.md)。

两条主线：**以 Chat 为入口的 Agent 工作台，以及 Agent Evaluation。** Chat 负责持续交互，Agent 负责执行，coding 是工具能力；用户在同一会话完成问项目、讨论需求、授权修改、查看结果和追问。

## 当前路线：v0.7 后端

围绕一次 Agent 编码任务，先梳理提交、入队、领取、执行和结果查询的现有契约，再依据可复现的缺口推进后端改造。阶段规划与首批验收标准见 [v0.7 后端路线](v0.7/plan.md)。

先明确本批问题、范围、方案和完成条件；用户明确要求实施后再改代码，测试与真实模型调用按当次授权执行。本轮只整理计划和状态，不启动 D1 实现或测试。

保留原始失败及历史材料，区分模型自报完成、工程检查、任务评分和独立验收。真实仓库修复沿用 AGENTS.md 的 G/R/P 流程；运行材料留在被忽略的 runs/、experiments/，本机留存不代表远端备份。提交、推送及历史清理按当次授权。
