# V0.7 双需求交接定向验收

2026-11-24（北京时间），定向验收通过。独立开发者账号 `handoff-reader` 从项目首页出发，用 Edge 完成 8 个页面观测点。浏览器按页面链接和按钮导航，任务编号和执行编号由页面路由生成。走查中未遇到产品断点。

## 环境与数据

使用新的隔离 Git 仓库、专用 PostgreSQL 数据库、独立 Redis 键空间、真实 HTTP API、独立 Worker 进程和独立 Edge 浏览器配置。需求提交、审批和接收通过正常 API 准备，交接走查使用另一个具备项目开发者权限的账号。Worker 用脚本模型驱动普通 Chat、两轮编码和返工，工具实际修改测试仓库并运行 pytest。真实 Provider 的构造入口和模型 HTTP 调用在模型初始化前均设为立即失败并记录尝试。成功轮记录脚本模型调用 7 次，拦截触发 0 次，真实模型调用 0 次。
