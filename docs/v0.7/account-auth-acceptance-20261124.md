# 账号与会话首批验收

2026-11-24（北京时间）。首批账号登录、会话撤销和统一访问控制通过定向验收。账号模式由 API 的 `--auth` 显式启用。

| 验收项 | 实际结果 | 证据 |
| --- | --- | --- |
| 登录与限流 | 本机管理命令创建管理员和普通账号。规范化登录名可登录，未知登录名与密码错误均返回 `401`，超过失败窗口配额返回 `429`。 | 真实 PostgreSQL、Redis 和 HTTP 集成用例 |
| 单会话退出 | 两份隔离 Edge 配置以同一账号登录。退出其中一份后，该会话返回 `401`，另一份保持 `200`。退出前的 Redis 原值写回后，被撤销的会话仍返回 `401`。 | Edge 实机验收、旧值写回集成回归 |
| 账号禁用与会话到期 | 禁用后两份 Edge 配置的旧会话均返回 `401`。重新启用后旧会话仍无效，新登录成功。Redis 会话到期后也返回 `401`。 | Edge 实机验收、Redis TTL 集成用例 |
| 统一鉴权与入队 | 未登录、普通账号、管理员缺少 CSRF 令牌的提交分别返回 `401`、`403`、`403`。每次拒绝后按任务 ID 查询 PostgreSQL，调度记录均为空。合法管理员请求返回 `202` 并产生排队记录。普通账号访问本地文件入口返回 `403`。 | HTTP 与 PostgreSQL 集成用例、Edge 实机验收 |
| Redis 连接故障 | 临时 TCP 代理切断测试 API 的 Redis 连接，浏览器收到 `503` 并显示暂不可用。连接恢复后原会话继续使用。退出删除失败时返回 `503`，响应未清除 Cookie。 | Edge 实机验收、删除故障注入用例 |
| SSE | Redis 断连与退出都使已打开的流关闭，随后重连分别返回 `503` 和 `401`。流内复核失败时，下一页事件未发送。 | 真实 HTTP 流、定向传输用例 |
| CLI 与凭据 | 真实 Windows 凭据管理器完成登录、身份查询、受保护读取和退出。退出后测试凭据已清理。CLI 凭据替身用例验证成功写入任务请求；凭据库写入失败时 CLI 返回业务错误并尝试撤销未保存的会话。 | Windows 登录会话、CLI 集成用例 |
